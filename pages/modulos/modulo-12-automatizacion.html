Personalización y Automatización

Optimiza tu flujo de trabajo con aliases, plantillas, scripts y AutoLISP.

Objetivos del módulo

Crear aliases propios, montar plantillas profesionales, automatizar tareas repetitivas con scripts y empezar con AutoLISP.

Alias de comando

Los alias son abreviaturas (ej.: L = LINEA). Edítalos en ALIAS o desde OPCIONES > Perfil > "Aceptar"; el archivo de alias vive en acad.pgp. Añade los tuyos para las tareas más frecuentes y notarás una productividad inmediata.

Plantillas (.dwt)

Una plantilla guarda tu configuración ideal: unidades, capas, estilos de texto y cota, layout con rótulo y configuraciones de plot. Se crea con GUARDARCOMO > tipo .dwt. Cada proyecto nuevo empieza desde tu plantilla y ahorra horas.

Scripts (.scr)

Un script es una lista de comandos en un archivo de texto que AutoCAD ejecuta en orden. Se carga con SCRIPT (SCRIPTS). Ejemplos: configurar capas, cargar tipos de línea o generar vistas de un dibujo. Cada línea es un comando o respuesta; una línea en blanco equivale a Enter.

AutoLISP

AutoLISP es el lenguaje de programación integrado de AutoCAD. Permite crear funciones a medida, automatizar secuencias y personalizar el entorno. Ejemplo básico de una función que traza un círculo:

(defun c:CIR () (setq r (getreal "Radio: ")) (command "_CIRCLE" "0,0" r))

Cárgalo con CARGAR (APPLOAD) y ejecútalo escribiendo CIR. Los archivos usan la extensión .lsp.

DIESEL y campos de sistema

DIESEL es un lenguaje de macros para la barra de estado y las propiedades personalizadas. Junto con los campos (CAMPO) puedes automatizar el contenido del rótulo: fecha, escala, nombre de archivo y datos de proyecto sin escribir nada a mano.

Práctica final

Crea una plantilla .dwt con tus capas y estilos, añade un alias para tu comando favorito y escribe un pequeño script que configure el dibujo. Si te atreves, carga la función CIR de AutoLISP de este módulo.
