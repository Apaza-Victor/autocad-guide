Textos, Tablas y Estilos

Anota, organiza información y automatiza datos con texto y tablas profesionales.

Objetivos del módulo

Usar texto de una línea y multilínea, configurar estilos de texto, crear tablas y trabajar con campos de datos automáticos.

Texto de una línea (DT)

TEXTO (DT) crea líneas de texto simples e independientes. Elige punto de inserción, altura y ángulo. Ideal para etiquetas cortas. Recuerda pulsar Enter dos veces para terminar.

Texto multilínea (M)

TEXTM (M) abre el editor de párrafos: permite varias líneas, justificación, columnas, símbolos y formatos enriquecidos. Es la herramienta para notas, pliegos y memorias técnicas dentro del plano.

Estilos de texto

Con ESTILO (ST) defines fuentes, altura, relación ancho/alto y efectos. Crea estilos según la norma de tu proyecto (ej.: altura de 2.5mm o 3.5mm). Los estilos anotativos ajustan automáticamente la altura según la escala de lámina.

Tablas

TABLA (TAB) inserta una tabla real con celdas, encabezados y fórmulas. Configura el estilo de tabla (ESTILOTAB): bordes, fuentes, colores y formatos. Vincula tablas a datos externos con VINCULODATO para listas de materiales actualizadas desde Excel.

Campos automáticos

Los campos muestran información que se actualiza sola: fecha, área de un polígono, número de página o el nombre del archivo. Inserta un campo desde el menú contextual del editor de texto. Al guardar o imprimir, los campos se refrescan.

Comandos clave

ComandoFunción
TEXTOTexto de una línea.
TEXTMTexto multilínea (párrafo).
ESTILOGestiona los estilos de texto.
TABLAInserta una tabla.
ESTILOTABConfigura el estilo de las tablas.
EDTEXTOEdita un texto existente.

Precaución

No uses texto con altura fija en planos con escalas distintas: usa estilos anotativos o crea un estilo por escala. Evita fuentes poco legibles que no se impriman bien en papel.

Práctica

Crea un estilo de texto anotativo de 2.5mm, escribe una etiqueta con TEXTO y una nota larga con TEXTM. Inserta una tabla de 3 columnas y añade un campo de área automático en una celda.
