Módulo 10 de 12 · Nivel Avanzado

Modelado 3D

Crea sólidos y superficies tridimensionales partiendo de tus dibujos 2D.

Objetivos del módulo

Trabajar con vistas 3D, crear sólidos primitivos, generar formas por extrusión/revolución/barrido y combinar geometría con operaciones booleanas.

Vistas y visualización 3D

Cambia de vista con VISTA (V) o desde la cinta: isométrica, planta, alzado. Usa ViewCube y ORBITA3D (mantener Shift + rueda) para rotar libremente. Con PERSPECTIVA alternas entre vista paralela y perspectiva.

Sólidos primitivos

BOX (caja), ESFERA, CILINDRO, CONO, CUÑA y TOROIDE crean sólidos listos para usar. Define centro, radio y altura con precisión, igual que en 2D.

Generación por perfiles

  • EXTRUSION (EX): eleva un perfil 2D cerrado una altura determinada. Opción Conicidad para caras inclinadas.
  • REVOLUCION (REV): gira un perfil alrededor de un eje. Ideal para piezas torneadas.
  • BARRIDO (BARRIDO): recorre un perfil a lo largo de una trayectoria (tuberías, molduras).
  • SOLEVAR (SOLEVAR): une varios perfiles para crear transiciones suaves.

Operaciones booleanas

Combinan sólidos para crear formas complejas: UNION (une), DIFERENCIA (resta) y INTERSECCION (zona común). Ejemplo: una pieza con agujeros se crea dibujando el cuerpo y restando los cilindros de los taladros con DIFERENCIA.

Superficies y mallas

Las superficies (no tienen espesor) se crean con SUPLANAR, SUP3D o SUPERFICIE y sirven para formas orgánicas. Las mallas son más densas; conviértelas a sólido cuando necesites operaciones de ingeniería.

Comandos clave

ComandoFunción
EXTRUSIONEleva un perfil 2D.
REVOLUCIONGira un perfil alrededor de un eje.
BARRIDORecorre un perfil por una trayectoria.
UNIONUne sólidos.
DIFERENCIAResta sólidos.
INTERSECCIONMantiene la zona común.

Precaución

Para extruir, el perfil debe estar cerrado (polilínea cerrada o región). Usa REGION para convertir curvas 2D en áreas extruibles. Revisa la vista isométrica a menudo.

Práctica

Dibuja la planta de una pieza, extruye 50mm con EXTRUSION, añade dos cilindros y réstalos con DIFERENCIA para crear los agujeros. Gira la vista con ORBITA3D para comprobarlo.
