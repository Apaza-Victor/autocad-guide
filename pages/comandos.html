Truco esencial

Enter permite continuar con la herramienta usada recientemente. Por ejemplo: escribe RR y pulsa Enter para recortar, o C y Enter para dibujar un círculo.

Consejo Pro

Si un comando no te funciona en español, escribe un guion bajo antes del comando en inglés (por ejemplo: _TRIM para recortar o _OFFSET para desfase) y AutoCAD lo reconocerá sin importar el idioma del programa.

Nota sobre Modos y Términos Técnicos

Algunos modos y términos se mantienen en inglés porque son universales en todas las versiones de AutoCAD:

  • OSNAP (F3) = Ajuste a Objetos / Adpuntar
  • ORTHO (F8) = Modo Orto / Ortogonal
  • GRID (F7) = Cuadrícula
  • SNAP (F9) = Ajuste a Cuadrícula
  • POLAR (F10) = Rastreo Polar
  • OTRACK (F11) = Rastreo de Objetos
  • DYNMODE (F12) = Entrada Dinámica
  • UCS = Sistema de Coordenadas de Usuario
  • XREF = Referencias Externas
  • DWG = Formato de archivo de AutoCAD
